# The shared schedule changes the computational problem

Define UNIQUE COPY WINNER: given M binary per-root score vectors, a named target, and B, can at most B distinct roots be copied once, with the same copy set applied to every model, such that the target strictly exceeds every rival? This is a finite evaluation problem, not a population statement.

The decision problem is NP-complete when the number of rivals is part of the input. Membership in NP follows by verifying the selected root indices and all score sums.

Reduction from SET COVER. For universe U and sets S_1,...,S_n, make one target and one rival per element e. For each set S_i, create a root where the target scores 1 and rival e scores 0 iff e belongs to S_i, otherwise 1. Write c_e for the number of sets containing e. For each element e, add c_e padding roots with target score 0, rival e score 1, and every other rival score 0. Each rival and the target now have exactly n correct answers, so the initial leaderboard is tied. A selected set-root increases the target-minus-e margin by 1 exactly when it covers e. A selected padding root only decreases one such margin; removing it never hurts feasibility and uses fewer copies. Consequently the target can become a unique winner with at most B copies iff B of the original sets cover U. The construction uses n+sum_e c_e roots and is polynomial. B need not exceed n because a cover never needs more than n sets.

This is closely related to classical constructive control by adding voters in approval voting, where candidates are systems and binary score rows are approval votes. Hemaspaandra, Hemaspaandra and Rothe (AAAI 2005, Anyone but Him: The Complexity of Precluding an Alternative) already establish NP-completeness of approval voter-addition control. This note supplies a direct reduction for the restriction that each added row must copy an existing root once. It is an explicit boundary for this evaluator threat model, not a claim that NP-completeness of election control or multidimensional selection is new.

The implementation compresses identical binary outcome patterns into integer count variables x_p in [0,N_p]. For target t and every rival j, impose sum_p (a_tp-a_jp)x_p >= C_j-C_t+1. Minimize sum_p x_p subject to sum_p x_p<=B. All feasible witnesses are independently recomputed in integer arithmetic. HiGHS optimal/infeasible statuses remain solver conclusions; the sorting certificate and exhaustive small-instance tests provide separate checks.

A counterexample to pairwise-to-joint reasoning is target=(1,1,0,0), rival1=(0,1,1,0), rival2=(1,0,0,1), B=1. Copying the first root beats rival1 and copying the second beats rival2, but no single copy beats both; two copies do.
